# The Perfect Pickup Line

A single original pickup line for make.fun's "The Perfect Pickup Line" bounty, delivered by a tiny Python program. No recycled joke, no grand rehearsed compliment — just an honest admission that having no plan at all turned out to be the plan, the moment someone smiled. The program writes exactly that one line to `entry.txt` so the judge reads the line and nothing else.

> I came here with no plan at all — then you smiled, and suddenly my whole plan is just hoping you do it again.

## Why it works

- **Honest, not rehearsed.** Admitting you had no plan is disarming — honesty reads as confidence.
- **The compliment belongs to her.** The smile is what changed the evening, so the praise feels earned, not flung.
- **Zero pressure.** It ends on a hopeful wish instead of a demand for a number, so the door stays open.
- **One sentence, speakable.** Short enough to say out loud once and still land.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat out/entry.txt
```
