One original one-line pickup line, written for the
[make.fun bounty "The Perfect Pickup Line"](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6).
`main.py` writes exactly that line to `entry.txt`.

> I rehearsed a pickup line all the way over here, but then you smiled and it filed for early retirement.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is not set).
